# Welcome to the Claude Code & Cowork Course

Welcome! You're about to learn how to use two of the most powerful AI tools at Thumbtack — **Claude Code** and **Cowork**. And the cool part? You're learning inside the tool itself.

This folder you just opened? It IS the course. The file that makes Claude your tutor right now? That's a `CLAUDE.md` file — and by the end of this course, you'll know how to build your own.

## What You'll Walk Away With

By the end of this course, you will:
- Understand when to use **Chat**, **Cowork**, and **Claude Code** (and why it matters)
- Have connected your key tools (Slack, Gmail, Calendar, Granola, and more)
- Have completed real tasks in Cowork and built real things in Claude Code
- Know how to use **plan mode** to think before you build
- Have designed and built **use cases specific to your role**
- Be able to create **custom skills** that automate your workflows
- Feel confident working independently with these tools

## Our Core Agreements

Before we dive in, here are the principles that guide this course:

### 1. Use AI to Ask AI
Your first line of defense for any question is to ask Claude. Stuck on something? Ask Claude. Not sure how something works? Ask Claude. That's literally what it's here for.

### 2. Progress Over Perfection
You don't need to get everything right the first time. The goal is to keep moving forward, learning as you go. Done is better than perfect.

### 3. Take Every Speed Bump as a Learning Opportunity
Things will break. You'll get unexpected results. That's not failure — that's learning. Each hiccup teaches you something about how these tools work.

### 4. Be Okay with the Imperfect
AI outputs aren't always perfect on the first try. That's normal. The skill is in knowing how to iterate, refine, and guide the AI to what you need.

### 5. Always Verify Output
Claude is confident even when it's wrong. Before you trust any output, check the assumptions, look for gaps, and think about what could break. The [AIRCRAFT Judgment Rubric](https://coda.io/d/_d65keLkjPAQ/AI-RCRAFT-Judgment-Rubric_suFNbe1a) is a great framework for this — bookmark it.

## How This Course Works

**Sessions:** Each lesson takes about 5-10 minutes. You can stop anytime and come back later — your progress saves automatically.

**Structure:** Every lesson has three parts:
- **Learn** — Claude teaches you a concept conversationally
- **Practice** — You build something real with Claude's guidance
- **Challenge** — A stretch goal for you to try independently

**Commands:** You have a set of commands to navigate. Just type these as a message:
- `course` — See the full course menu
- `lesson` — Start or resume where you left off
- `skip 2.03` — Jump to any lesson
- `progress` — See your stats and badges
- `hint` — Get help on an exercise
- `check` — Validate your work
- `exit` — Leave the course with a summary

> 💡 **Using the CLI?** If you're running this course in Claude Code's terminal (CLI), these also work as slash commands — type `/course`, `/lesson`, etc. In the **desktop app**, just type the keyword as a regular message.

**Building real things:** The exercises in this course are NOT pre-made problems with pre-made answers. You'll build things that are **actually useful to you and your role**. Claude will help you identify what to build and guide you through it.

**Videos:** Some lessons include short Loom demo videos. These are optional — watch them if you want to see something in action, but they're not required to progress.

**Questions:** Ask Claude anything, anytime. It's your tutor for the duration of this course. If your question is about something covered in a later module, Claude will point you there.

## A Heads Up: Accepting Edits

Throughout this course, Claude will create and edit files as part of your exercises. When this happens, you'll see a popup asking you to **allow** the edit. This is normal and expected!

You have two options:
- **Allow** — approves that one specific edit
- **Always allow for session** — approves all similar edits for the rest of your session (means fewer popups)

Either option is fine. As you learn more, you'll understand exactly what Claude is asking to do each time. For now, just click allow throughout this course — it's safe to do so within the course folder.
