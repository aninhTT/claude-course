# Module 4: Use Case Thinking

This is where things get personal. You'll feed Claude deep context about your work, learn plan mode, and identify and build real use cases.

## What You'll Learn

- How to give Claude rich context about your role and workflows
- How to copy and customize an existing use case skill
- **Plan mode** — Claude Code's essential tool for planning before building
- How to build a use case from scratch
