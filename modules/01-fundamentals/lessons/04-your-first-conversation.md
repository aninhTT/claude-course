# Lesson 1.04: Your First Conversation

## Learn

You've learned what Claude Code is, connected your tools, and understand why folders matter. Now let's actually have a real, productive conversation with Claude Code.

> Already comfortable with this topic? Skip ahead anytime with `skip` followed by the next lesson number.

### The Art of Good Instructions

Claude Code is incredibly capable, but it works best when you give it clear context. Here are the key principles:

**Be specific about what you want.** Instead of "help me with my work," try "Help me draft a weekly status update for my team based on what I've done this week."

**Give context about your role.** Claude can tailor its help dramatically when it knows who you are. "I'm a project manager on the marketplace team" changes everything about how Claude responds.

**Start with a question, not a command.** One of the best first moves is to ask Claude how it can help you. This lets Claude understand your situation before jumping into action.

**Iterate, don't start over.** If Claude's first response isn't quite right, refine it. "That's good but make it more concise" or "Focus more on the budget aspect" is how you get great results.

**Voice dictation is your best friend.** You can speak context much quicker than you can type it. Claude supports voice input directly — look for the microphone icon. You can also use a third-party tool like Wispr Flow for even faster dictation anywhere on your computer. When you need to dump a lot of context about your role, your workflows, or a problem — just talk. It's faster, more natural, and you'll share richer detail than you would typing.

### Where Does Claude Put Things It Creates?

When Claude Code creates a file, it saves it in your current folder (or a subfolder you specify). This is critical: **you need to know where Claude is creating things.** If you ask Claude to build a template and it saves it, you can find it right in your folder. This is another reason why folders matter so much — everything Claude creates lives in your project folder where you can see it, edit it, and use it.

### Reading and Editing Files

Claude Code can read and edit files in your current folder. This is a superpower:
- Ask it to read a file and summarize it
- Have it create new files
- Ask it to edit existing files
- It can work with any text-based file

### Managing Sessions

In the Claude Code app, each conversation is a **session**. Key things to know:
- Sessions persist — you can close the app and come back to the same conversation
- You can have multiple sessions open at once
- Each session remembers its context
- To start fresh, open a new session

We'll explore multiple sessions more in Module 2. For now, just know that this course session will remember your progress.

## Practice

Let's have your first real, productive conversation with Claude Code. Do this right here in this session.

**Step 1:** Start with this prompt — fill in your actual role:

> "How can Claude Code and Cowork support me as a [your role]? What are the top 5 things you could help me with on a daily basis — and for each, tell me whether Claude Code or Cowork would be the better tool."

Read Claude's response. Does it resonate? Tell Claude which suggestions are most relevant and which aren't.

**Step 2:** Pick one of the suggestions and ask Claude to actually do it (or start it). For example:
- If Claude suggested "draft your daily standup update" → ask it to draft one for today
- If Claude suggested "organize your meeting notes" → ask it to help with that
- If Claude suggested "create templates for recurring tasks" → pick one

> 💡 **Tip:** Try using voice dictation for this step! Tap the mic icon and just talk about what you need. It's faster than typing.

**Step 3:** Iterate on the result. Give Claude feedback: "Make it shorter," "Add more detail about X," "Change the tone to be more casual."

**Success criteria:** Had a multi-turn conversation with Claude Code about their actual role, got a useful output, and iterated on it at least once.
