# Lesson 1.01: Claude Code vs Chat vs Cowork

## Learn

At Thumbtack, you have access to three Claude-powered tools. They share the same AI "brain" but are designed for different jobs. Understanding when to use each one is the most important thing you'll learn today.

But before we get into the tools, here's the single most important habit you'll build in this course: **state your goal clearly before you start.** Research across tens of thousands of Claude conversations shows that people who articulate what they want upfront — before Claude does anything — get dramatically better results across everything else. It doesn't matter if it's one sentence or a whole paragraph. What matters is that you've thought about what you actually need before Claude starts working.

### Chat — Your Thinking Partner

**Claude Chat** (claude.ai) is your brainstorming buddy. Use it when you need to:
- Think through a problem or outline an approach
- Rewrite, summarize, or polish content
- Get a quick answer to a question
- Have a back-and-forth conversation to refine ideas

Chat's superpower is **Projects and Memory** — you can save context that carries across conversations. We don't cover Chat super extensively in this course because if you've used ChatGPT, it'll feel familiar — it's a similar back-and-forth experience. The main difference is that Claude can't generate images. If you want a primer on how best to engage with Chat-style AI interfaces (which have a ton of similarities across tools), check out the **30 Days of AI** series: https://thumbtack.haystack.so/resources/0041286c-fdad-442a-b4db-dfd57e08ae53

### Cowork — Your Task Executor

**Cowork** is your autonomous assistant. Point it at a task and let it run. Use it when you need to:
- Execute multi-step tasks (research, compile info, draft communications)
- Index and synthesize information from Slack, email, Granola
- Follow a plan autonomously without needing your input at every step

Cowork is built on the same "brain" as Claude Code but optimized for **task execution**. You give it clear instructions, point it at a folder for context, and it works through the task. It does NOT have plan mode — it just executes.

### Claude Code — Your Builder

**Claude Code** is where you build things. Use it when you need to:
- Create tools, automations, scripts, or apps
- Write and run code
- Build custom skills and workflows
- Work with files and folders directly
- Prototype ideas quickly

Claude Code has **plan mode** — always plan before you build! It can read, write, and run files on your computer. This is the most powerful tool in the trio, and one of the focuses of this course.

### The Key Differences

| | Chat | Cowork | Code |
|---|------|--------|------|
| **Best for** | Thinking | Doing tasks | Building |
| **Interaction** | Back-and-forth | Set it and go | Collaborative building |
| **Plan mode** | No | No | Yes — use it! |
| **File access** | No | Folder context | Full read/write |
| **Sessions** | Conversations | Tasks | Sessions |

### Quick Rule of Thumb

- **Need to think?** → Chat
- **Need it done?** → Cowork
- **Need to build it?** → Claude Code

### The Three Modes in Claude Code

Claude Code has three modes you'll encounter — each serves a different purpose:

- **Ask permissions (default)** — Claude proposes an action (like editing a file or running a command) and waits for you to approve. This gives you full control over what happens. You'll see popups asking you to "Allow" — this is normal.
- **Auto accept edits** — Claude makes edits without asking first. Useful when you trust the workflow and don't want to click "Allow" for every change. Great for experienced users.
- **Plan mode** — Claude thinks through an approach *before* building anything. It creates a plan, you review it, then Claude executes. Always use this when building something new or complex.

You'll learn more about when to use each as the course progresses. For now, just know they exist.

### One Important Note: There's Overlap

These three tools — Chat, Cowork, and Code — don't have perfectly rigid boundaries. Sometimes a task could work in more than one tool. That's fine! The "when to use what" table is a guide, not a rulebook. Trial and error is important here — the more you use them, the more intuitive it gets.

## Practice

Let's make sure the distinction is clear. For each scenario below, tell me which tool you'd use (Chat, Cowork, or Code) and why:

1. You need to draft talking points for a meeting tomorrow
2. You want to pull together a summary of all Slack messages about a project from the last week
3. You want to build a daily checklist template that auto-populates with your calendar events
4. You're trying to decide between two approaches for a presentation
5. You need to index your email and Granola notes to prep for a 1:1

**Success criteria:** Correctly identify the right tool for at least 4 out of 5 scenarios with reasoning.

## Challenge

Think about your last work week. Identify:
- **One task** you did that would have been perfect for Chat
- **One task** that would have been perfect for Cowork
- **One task** that would have been perfect for Claude Code

Describe each briefly. Bonus: For the Claude Code task, what would you have it build?

> **Before you're done — Question It:** What did Claude assume? What's missing? What could break?

**Success criteria:** Identified 3 real tasks from their work with appropriate tool mapping and brief explanation.
