# Module 1: Fundamentals

Welcome to the foundation. This module covers everything you need to start using Claude Code with confidence.

## What You'll Learn

- The difference between **Chat**, **Cowork**, and **Claude Code** — and when to use each
- How to connect your tools (Slack, Gmail, Calendar, Granola, and more)
- Why folders are the foundation of everything in Claude Code
- How to have your first productive conversation with Claude Code
- How to build your first useful artifact

## By the End of This Module

You'll understand the Claude ecosystem, have your tools connected, and have built something real in the `workspace/` folder. You'll be ready to explore Cowork in Module 2.
