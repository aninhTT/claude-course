# Module 2: Cowork

Cowork is your autonomous task executor. You give it instructions, point it at your tools (or upload data), and it works through the task independently. This module takes you from first task to working independently with Cowork.

## What You'll Learn

- What Cowork is and how it relates to Claude Code
- How to run your first real Cowork task (with connectors or data files)
- Independent practice directing Cowork on your own
- Breaking work into agent-sized pieces

## By the End of This Module

You'll be comfortable directing Cowork for real tasks and know how to break work down for it. Next up: Skills & Plugins in Module 3.
