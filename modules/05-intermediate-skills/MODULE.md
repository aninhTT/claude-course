# Module 5: Intermediate Skills

You've built your first skills and identified your use cases. Now it's time to go deeper — master skill creation, learn to schedule and automate, and build a personal context system.

## What You'll Learn

- Creating custom skills from scratch with proper structure
- Scheduling and automating skills to run on their own
- Best practices and patterns for reliable skills
- How CLAUDE.md powers everything (and how to write a great one)
- Building context files that make Cowork feel personalized

## By the End of This Module

You'll be able to create, schedule, and maintain a personal toolkit of skills — backed by a context library that makes every output sound like you.
