# Workspace

This is your building sandbox. Course exercises will guide you to create files here.

## What Goes Here

- Artifacts you build during lessons (templates, documents, tools)
- Skills you create (SKILL.md files)
- Use case designs and prototypes
- Context files (like my-context.md)
- Anything you want to experiment with

## Tips

- Organize subfolders as your builds grow (e.g., `workspace/skills/`, `workspace/use-cases/`)
- Don't worry about keeping things neat at first — you can reorganize later
- Files here persist across sessions — they're yours to keep

Happy building!
